# docs/modelagem/

Diagramas UML e suas descrições. Os arquivos-fonte (`.drawio`) e as exportações (`.png`) devem ficar nesta pasta.

## Diagramas do projeto

| Diagrama | Finalidade | Requisitos |
|---|---|---|
| Casos de uso | Atores e funcionalidades (inclui `<<include>>` e `<<extend>>`) | RF01 a RF05 |
| Classes | Tutor, Pet, Veterinário e Consulta, com multiplicidades | RF01, RF02 |
| Estados | Ciclo de vida da Consulta (Criada, Confirmada, Em Andamento, Concluída, Cancelada) | RF03 |
| Sequência | Cancelamento de consulta e notificação orientada a eventos | RF05 |
